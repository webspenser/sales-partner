# 1.0.0 → 1.0.1

Your own examples (sample emails, posts, pages you supplied) now live in
the instance's `context/samples/`, not the package's `samples/`.

- Create `context/samples/` in the instance folder, and move any files
  you saved in `samples/` there. In plugin mode, check the instance
  folder for a stray `samples/` too.
- No other shape changes: context files are unchanged. Set
  `agent_version: 1.0.1` in `instance.yaml`.

`context/crm-contract.md` and `context/crm-airtable-adapter.md` are
package files from 1.0.1 on; an instance copy of either is no longer
read and can be deleted.
