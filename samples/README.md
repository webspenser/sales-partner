# Samples

This directory holds only the examples the agent ships with. Your own
examples go in your instance's `context/samples/` (the interview saves
them there); the agent reads those first. In plugin mode this package
folder is read-only.

Samples teach voice. This template ships none on purpose — a generic
sample would be copied into real output and nobody would notice it
happened.

Add three to five filled artifacts, written in the voice this agent
should produce, to `context/samples/` in your instance. Real ones, from
the actual business.

## Collect from the operator during the Phase 0 interview

- Three real cold emails that got replies.
- One real call brief, or a set of call notes, from an actual sales call.
- One real follow-up that revived a stalled deal.
